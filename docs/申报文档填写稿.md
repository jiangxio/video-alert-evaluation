## 一、评测工具具体描述

### 1. 工具介绍

视频水印Benchmark评测平台面向视频流AI算法常态化评测。通过对视频添加水印（视频ID+时间戳），OCR提取告警图片水印信息，与人工标注真值做时间窗口自动对齐，计算精确率、召回率、平均误检数/小时。覆盖任务创建→样本导入→评测计算→结果输出→报告生成全流程闭环，支持Docker一键部署。

### 2. 功能特色

- **水印基准法自动对齐**：为视频打水印（视频ID+时间戳），OCR提取告警图片水印即可与真值事件对齐，免去人工逐帧标注，评测过程自动化。
- **视频流时序评测**：以±5s容差时间窗口做告警与GT事件匹配，判定命中/误检/漏检；按事件类型分组计算精确率、召回率（算术平均）、平均误检数/小时。
- **全流程闭环**：任务创建、样本导入（ZIP批量）、评测计算、结果输出、报告生成（自包含HTML/PDF）一应俱全，数据库跟踪全生命周期。
- **三种交互方式**：命令行脚本（水印处理、OCR、验证、一致性核对）、REST API（182个端点）、Web可视化页面（22个模板），覆盖自动化集成与人工操作。
- **Docker一键部署**：`docker compose up -d` 即起 web(8080)+od(5000) 双服务，镜像内置 FFmpeg、字体、EasyOCR 模型、Chromium，离线可用，仅需修改 `.env` 一个配置文件。
- **多算法版本管理**：注册算法版本、配置文件与可执行文件，支持版本对比与追溯。
- **推流模拟**：RTSP 推流到 MediaMTX，模拟真实视频流做实时评测。
- **独立目标检测评测模块（od）**：矩形框标注、COCO/YOLO 格式导入导出、IoU/mAP 评测，与视频评测完全解耦（独立服务/DB/端口）。
- **评测结果确定性**：评测基于数据库持久化的OCR结果做确定性匹配，重复评测5次偏差0%；系统指标与人工验收基准对比 MAPE<1%。

### 3. 使用场景与部署方式

**适用评测场景**：
- **准入测试**：算法上线前，对真实视频流跑全量评测，验证精确率/召回率/误检频率是否达标。
- **版本回归测试**：算法版本迭代后，对比新旧版本指标，防止回归。
- **多算法对比选型**：同一评测集跑多个算法版本，横向对比指标择优。
- **常态化评测**：周期性评测已上线算法，监控质量衰减。
- **模型能力评测**：评估算法在光照变化、遮挡、角度切换等真实场景下的鲁棒性。
- 覆盖**视觉类**评测（视频事件检测、视觉异常检测、目标检测）；图像分类评测模块已设计（交接文档就绪，待实现）。

**部署方式**：
- 灵活便捷：Docker Compose 一键启动，无需复杂环境依赖（FFmpeg/字体/OCR模型/Chromium 均内置），参赛现场可能无外网时离线可用。
- 快速接入：仅需修改 `.env` 一个配置文件（API 密钥），无需专业技术团队全程支撑。
- 标准化：命名卷持久化数据，重建容器不丢数据；支持配置覆盖（告警类型、算法配置）。

### 4. 技术创新性与自主性

**关键技术**：水印基准法——用 FFmpeg drawtext 为视频添加"视频ID|时间戳"水印，被测算法对水印视频运行产出告警图片，OCR 提取水印中的视频ID与时间戳，即可将告警自动对齐到人工标注的真值事件区间。相比传统逐帧人工标注对齐，大幅降低标注成本且对齐客观可复现。

**技术创新点**：
1. 水印基准法实现告警与真值的自动时间对齐，免去逐帧人工标注。
2. 评测计算基于持久化OCR结果做确定性匹配，结果可复现、偏差0%。
3. 视频流时序评测指标体系（精确率/召回率/误检小时，按类型宏平均）。
4. 评测工具在自身命题场景下的创新性优化：CPU纯OCR离线运行、低资源消耗。

**自主性**：
- 具备完整自主研发能力，全部源码及技术文档可完整提交。
- 核心模块（水印生成、OCR预处理、评测计算、指标统计、报告生成）均为自主研发。
- 基础框架采用开源组件并遵循开源协议：Flask（Web）、EasyOCR（OCR）、Playwright（PDF渲染）、FFmpeg（视频处理）。

### 5. 评测效果

**真实验收佐证**：对8类安全监管模型在真实视频流场景完成验证——测试视频总时长4小时53分6秒，Ground Truth人工标注事件376条，覆盖8类事件场景；共产生告警2139条，其中正确告警1393条、误检97条、漏检124条。

**核心指标**（均达验收标准）：
| 指标 | 实测值 | 验收标准 |
|------|--------|----------|
| 整体精确率 | 95.5% | ≥85% |
| 整体召回率 | 85.2% | ≥80% |
| 平均误检数/小时 | 2.48 | ≤10 |

**结果可靠性**：
- 评测结果完全正确、可靠、可直接应用：基于持久化OCR结果确定性计算，重复评测5次偏差0%。
- 系统计算指标与人工逐条核对基准（验收报告）对比，精确率MAPE 0.89%、召回率口径一致，无需人工复核。

## 二、内部应用与效益分析

### 1. 内部应用需求分析

**（1）应用背景与痛点**
公司AI产品（视频流算法）版本迭代频繁，每次迭代需评测精确率/召回率/误检频率。传统方式痛点：人工逐帧标注成本高且不一致；缺乏标准化、可复用的常态化评测工具；评测结果难以对齐真值、主观不可复现；评测报告需手工拼凑。

**（2）目标客户分析**
- 算法研发团队：版本迭代后快速回归测试。
- 质检团队：算法准入与常态化质量监控。
- 产品团队：算法选型与能力评估。

**（3）应用前景**
视频流AI算法广泛应用于餐饮安全监管、安监、园区等场景。本工具的水印基准法可推广到各类视频流AI算法评测，微调参数即可适配新产品线。

### 2. 应用模式与推广策划

**（1）应用模式**
- 内部平台工具：Web可视化页面 + REST API，支持人工操作与自动化集成。
- 与CI/CD流水线集成：命令行脚本可纳入自动化流程，版本提交自动触发评测。
- 定期输出质量报告：HTML/PDF自包含报告，供存档与汇报。

**（2）内部推广可行性**
- 技术可行性：Docker标准化部署，镜像内置全部依赖，离线可用。
- 组织可行性：贴合公司现有AI产品常态化评测业务流程与格式规范（有真实验收报告佐证）。
- 成本可控性：基于开源框架自研，无额外许可费用；复用现有算力（CPU即可）。

### 3. 竞争者/竞品分析

- **通用评测脚本**（如OpenCV评估工具）：偏单帧静态评估，缺乏视频流时序评测、水印对齐、业务贴合，无闭环。
- **自建临时脚本**：无任务管理、无可视化、无报告生成，不可复用。
- **本工具优势**：业务贴合（真实验收佐证）、全流程闭环、水印基准法创新、Docker一键部署、三种交互方式。

### 4. 评测工具SWOT分析

- **优势**：水印基准法创新（免逐帧标注）；真实验收佐证（8类模型4h+视频）；Docker一键部署；三种交互方式；评测结果确定性（0%偏差）。
- **劣势**：聚焦视频流评测，文本类/多模态为辅（图像分类模块待实现）。
- **机会**：公司AI产品常态化评测需求明确，工具已成熟可用（验收过）。
- **威胁**：通用评测框架可能扩展；需持续扩充评测能力覆盖更多任务类型。
